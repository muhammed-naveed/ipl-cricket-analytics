# IPL Cricket Analytics

## Project Overview

A data analytics project exploring IPL cricket match data to understand the factors that influence match outcomes.

## Business Question

**What actually decides an IPL match, and what does that mean for how a franchise should prepare?**

## Dataset

The project uses IPL cricket data containing five tables covering 19 seasons from the approved project data source.

The data includes information about matches, deliveries, players, teams, and venues.
